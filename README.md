# Fuling Cyrene Driver

腹灵「崩坏：星穹铁道」昔涟·往昔的涟漪键盘的非官方、实验性 Windows 离线驱动。

> 本项目与腹灵、米哈游或《崩坏：星穹铁道》没有隶属或授权关系。使用前请保留原厂驱动，并自行承担第三方工具修改设备配置的风险。

本程序不加载 `qmk.top`，直接通过本地 HID 接口连接键盘有线接口 `38A9:0017` 或 `2.4G` 接收器 `3151:5052`，并已识别：

- 内部设备 ID：`4112 / 0x00001010`
- 底层配置：`Fuling Air 108 metallic`
- 协议代号：`ry6602_fl_k2509_3m_1k_1k`
- 能力：108 键、三层、主灯、侧灯、USB/2.4G/蓝牙

## 0.6.0 USB 有线测试版

0.6.0 增加 USB 有线直连传输。程序会优先验证 `38A9:0017` 的厂商控制接口与内部设备 ID，成功后直接读取和写入灯效、三层键位、Fn 层、宏与休眠参数；没有可用的有线接口时再回退到 2.4G 接收器。

## 0.5.2 电量颜色测试版

0.5.2 为电量百分比与进度条增加分段渐变颜色：`60%–100%` 为绿色，`21%–59%` 为黄色，`0%–20%` 为红色。

## 0.5.1 固定设计分辨率测试版

0.5.1 以 `1180 × 760` 作为启动内容区和固定设计分辨率。调整窗口大小时，整个界面按统一缩放因子等比缩放，不再按网页断点重新排版。

## 0.5.0 休眠时间测试版

0.5.0 开放休眠设置面板，可读取、备份、写入、回读校验和恢复 2.4G 浅休眠、蓝牙浅休眠与蓝牙深度休眠。2.4G 深度休眠参数仅读取并原值保留。

## 0.4.3 文本宏测试版

0.4.3 更换了应用与可执行文件图标，精简顶部文案，并在电量旁增加 USB 供电检测。该检测依据键盘有线接口 `38A9:0017` 是否被 Windows 枚举，无数据的纯充电线无法检测。

0.4.2 将配置功能移到功能面板上方，改为按键映射、灯光控制和宏设置三个可切换面板，页面每次只展示一项配置。

0.4.1 修复了 0.4.0 可能从过期快照恢复绑定键、导致原键被禁用的问题。现在会在写入宏前即时备份目标键，拒绝覆盖异常键值，并在恢复后独立回读校验。

除接收器状态、键盘在线状态、电量和内部设备 ID 外，当前版本已开放：

- 读取与控制主键区灯效
- 读取与控制侧灯灯效
- 调整效果、颜色、亮度、速度与炫彩模式
- 第一次读取时自动备份启动时灯效
- 每次写入后回读校验
- 一键恢复本次启动时灯效
- 读取并备份三层、108 键的完整键位矩阵
- 标准键盘按键的安全单键映射
- 单键写入后回读整层校验
- 按启动备份恢复本次运行中修改的键位
- 扫描普通三层以及 Windows/macOS Fn 层中的宏引用
- 将英文、数字、换行及常用英文符号转换为安全文本宏
- 宏槽与绑定键分别写入、回读校验和恢复
- 2.4G/蓝牙休眠时间的读取、备份、写入、回读校验和恢复

备份保存在应用数据目录下的 `lighting-backups`、`keymap-backups`、`macro-backups` 和 `sleep-backups` 文件夹。文本宏当前不支持中文或任意鼠标动作；媒体键、Fn、自定义功能键和组合键暂时只能作为原有键值保留。

目前灯效、键位、宏和休眠设置已经完成 USB 有线与 2.4G 实机读写回读验证。蓝牙通信将在后续版本单独验证。

## 使用方法

1. 从 [Releases](../../releases) 下载便携版程序。
2. 使用 USB 数据线连接键盘并切到有线模式；也可以插入 `2.4G` 接收器并唤醒键盘。
3. 首次修改前先在对应功能页点击读取/备份按钮，程序会自动创建恢复备份。
4. 写入完成后留意界面的回读校验结果；如需撤销，使用对应的恢复按钮。

程序目前未进行代码签名，Windows 可能显示 SmartScreen 提示。请只从本仓库 Releases 下载，并核对发布页提供的 SHA-256。

## 本地开发

需要 Node.js 与 npm：

```powershell
npm install
npm start
```

构建 Windows 便携版：

```powershell
npm run pack
```

## 隐私与安全边界

- 程序不加载在线驱动网页，也不上传键盘数据。
- 设备配置备份只保存在本机 Electron 应用数据目录。
- `backups/`、协议分析缓存、构建产物和依赖目录均被排除在 Git 仓库之外。
- 当前只对内部设备 ID `4112`、有线接口 `38A9:0017`、接收器 `3151:5052` 和协议 `ry6602_fl_k2509_3m_1k_1k` 做过实机验证。
